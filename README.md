# 坦白局 · 双人版（tanbai-duo）

两个人共用一部手机玩的真心话大冒险网页。不需要服务器，打开 `index.html` 就能玩。

## 文件分工

| 文件 | 内容 | 谁来改 |
|---|---|---|
| `questions.js` | 题库（现在全是占位题） | Grok（内容） |
| `style.css` | 颜色、字体、布局 | ChatGPT（界面优化） |
| `index.html` | 页面结构 | 尽量不改；要改的话不能删改任何 `id` |
| `app.js` | 游戏逻辑 | Claude |

## 玩法规则（框架已实现）

- 起始档位四选一：1 温和 / 2 暧昧 / 3 私密 / 4 缠绵；总轮数默认 10
- 第 1 轮玩家1 问玩家2，之后两人轮流出题
- 出题人看到两张牌（一张真心话、一张大冒险），每轮可以换一次牌
- 被问的人只看到类别，盲选一张，然后揭晓
- 选「做到了 / 答了」或「逃了」；逃了的人之后升一档（最高缠绵）
- 每满 5 轮，两人都升一档
- 大冒险可以带倒计时
- 结束后出战报卡：每人答了几题、逃了几题、最终档位，以及最大胆的一题
- 中途刷新或关掉页面，可以点「继续上一局」

## 给 Grok 的题库格式（整体替换 questions.js）

```js
window.QUESTIONS = [
  { id: "t1-truth-01", tier: 1, type: "truth", category: "心事", text: "题目内容" },
  { id: "t1-dare-01",  tier: 1, type: "dare",  category: "动作", text: "题目内容", seconds: 30 },
];
```

- `id`：每题唯一，不能重复
- `tier`：数字 1–4（1 温和、2 暧昧、3 私密、4 缠绵）
- `type`：只能写 `"truth"`（真心话）或 `"dare"`（大冒险）
- `category`：小类别，盲选时会显示给被问的人看，所以不要透露题目内容（2–4 个字）
- `text`：题目正文
- `seconds`：只有大冒险需要，表示倒计时秒数；不需要计时就不写
- 数量：**每个档位的真心话、大冒险各至少 30 题**，这样玩 10 轮不会重复
- 文件第一行必须是 `window.QUESTIONS = [`，最后一行必须是 `];`
- 格式写错的题会被自动跳过，开局页会显示跳过了几题

## 给 ChatGPT 的界面优化规则

- 只改 `style.css`
- 不要改 `index.html` 里任何 `id`；`app.js` 用到的 class（`hidden`、`screen`、`card`、`card-text`、`blind`、`swap`、`pick`、`badge`、`tier1`–`tier4`、`btn`）只能改样式，不能改名字
- 改完先在手机上从头到尾玩一局，确认没有问题再提交
